## Real-host failure

Windows/Git Bash reached the mandatory local pre-upgrade capture and PostgreSQL failed with a host path inside the Linux container:

```text
pg_dump: error: could not open output file "C:/Users/.../AppData/Local/Temp/preupgrade-....dump": No such file or directory
ERROR: PostgreSQL capture failed; no recovery bundle was published.
```

## Root cause

The pre-upgrade script intentionally used container temporary files under `/tmp/preupgrade-*`. Git Bash/MSYS automatically rewrote those `/tmp/...` command-line arguments when invoking native `docker.exe`, turning them into Windows host paths before `docker exec` delivered them to the Linux PostgreSQL container.

## Repair

`c4bf03f1238f47faafaecff59705a9e44ced717d` sets `MSYS_NO_PATHCONV=1` on every Docker boundary in `scripts/hybrid/create-local-preupgrade-backup.sh` that carries container paths: capture `docker exec`, the three `docker cp` operations, and cleanup `docker exec`. This follows the existing repository pattern used by other Docker commands that pass Linux container paths.
