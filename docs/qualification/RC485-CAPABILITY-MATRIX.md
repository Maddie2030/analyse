- **Reading/history:** retain History, Recently Opened, Continue Reading and exact read/completion evidence; retire runtime dependence on historical `reading_history` after one-time migration. Normal Library does not reconstruct truth by merging a second Progress history response.
- **Web local reading:** retain immediate local pending state and background synchronization through one repository. Old writable unscoped local Progress keys are not a canonical server owner.

- **Publication:** retain every manual/scraper/batch/new-series path and supported upload format; retire direct production Catalog-table writers in Scraper/Media only after P06 replacement commands work.

- **Cleanup:** retain exact-object lifecycle cleanup and retry. Broad prefix deletion is not a retained authority when it can affect another generation/output.
- **Dashboard:** Web `/dashboard` is a compatibility navigation redirect to `/library`, not another persistent state owner.
