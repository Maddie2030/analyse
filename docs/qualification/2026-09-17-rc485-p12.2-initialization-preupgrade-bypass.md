## Change

```env
MREADER_SKIP_PREUPGRADE_BACKUP=true
```

- default in `.env.example`: `false`;
- when `true`, `scripts/hybrid/stateful-up.sh` emits a warning and skips only `create-local-preupgrade-backup.sh` for that run;
- migrations/reconciliation continue normally;
- normal upgrades remain protected because the default is `false`;
- scheduled backup enablement remains controlled independently by `POSTGRES_BACKUP_ENABLED`.
