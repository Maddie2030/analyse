## Root cause and repair

The Windows bootstrap/hybrid validation failed because P12.4 introduced direct host `python` invocations in the Graphify development-reference builder and its static regression. Those calls bypassed the existing cross-platform `scripts/hybrid/python-runtime.sh` abstraction.

P12.6 routes all development-reference Python execution through the shared runtime, preserving local Python when available and the pinned Docker Python fallback when it is not. A focused regression prevents direct host Python from returning.
