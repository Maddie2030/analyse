## What changed

The containerized diagnostics module now has a real actor-acceptance layer in addition to complete route/API coverage and runtime evidence capture.

User actor journeys assert account/profile/login/logout, catalog taxonomy/discovery/search/chapter detail, bookmarks, subscriptions, ratings/metrics, comments, Smart Library, reader manifest/image access, progress/history/series state, notification count/single-read/read-all.

Admin actor journeys assert admin statistics, safe database-protection status, series metadata/status/tags, editor picks, announcements, draft chapter create/edit/delete/validation, media chapter publication/deletion, scraper staging and publication.

Full diagnostics also runs the Playwright user/admin browser suite unless `--no-browser` is selected. Optional real inputs can be supplied with `--scraper-series-url`, `--scraper-chapter-url`, `--chapter-file`, and `--cover-image`; missing optional inputs are skipped rather than failed.

The first real diagnostic report also drove harness correctness fixes: pytest path portability, false `OOMKilled:false` classification, stale probe/refusal promotion, RabbitMQ success-line matching, and the PostgreSQL runtime-count collector.
