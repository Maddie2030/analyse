# RC4.85 P09.2 Ownership / Route Manifest Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create and verify one machine-readable ownership contract for every current in-scope MReader HTTP operation without changing route exposure, database grants, readiness logic, or runtime behavior.

**Architecture:** Extend the existing route audit so one parser produces canonical source-route records with handler provenance. Keep semantic ownership explicit in `contracts/ownership/routes.v1.json`, validate its structure with `routes.schema.v1.json`, and use a dedicated auditor to cross-check the manifest against current route source, endpoint coverage, both Caddy gateway planes, obvious authentication boundaries, evidence paths, and first-party literal consumers. P09.3-P09.5 may consume the manifest only after this same-source audit passes.

**Tech Stack:** Python 3 standard library, JSON/JSON Schema artifact, Bash entrypoint, current Go/Python/TypeScript route sources, Caddy configuration, unittest regression tests.

**Spec:** `docs/superpowers/specs/2026-09-16-rc485-p09.2-ownership-route-manifest-design.md`

## Global Constraints

- Preserve `scripts/tests/api-route-audit.py` as the source-route / `tests/api/endpoint_coverage.tsv` coverage authority; do not fork a second route parser.
- P09.2 contains current source routes only. Planned-only routes from `reference/p09.2-manifest-wip` are evidence, not authority.
- Do not change live route exposure, Caddy routing, application authentication, database grants, workload secrets, readiness, restore behavior, or P06-P08 ownership semantics.
- Manifest route-set equality is exact against the current source inventory and `tests/api/endpoint_coverage.tsv`.
- All HTTP mutations declare explicit semantic write authority or an explicit side-effect-free command exception proven by evidence.
- Internal routes may not declare browser consumers or browser-session authentication.
- P09.3 consumes only audited `kind=postgres` write descriptors; P09.4/P09.5 consume only manifests that pass the P09.2 audit on the same source tree.
- No new runtime Python dependency is allowed; schema and semantic validation must run with the Python standard library in this repository environment.
