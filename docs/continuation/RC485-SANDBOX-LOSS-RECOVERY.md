## New durability rule

A Drushti milestone is not complete merely because source and tracker are committed locally.

Every meaningful reconstructed source+tracker checkpoint must also:

1. create a fresh all-refs Git bundle;
2. prove the new HEAD and required branches/stash are present in the bundle;
3. build a continuation ZIP;
4. create and verify SHA-256;
5. persist/replace the Library continuation artifact;
6. materialize/verify the persisted artifact or otherwise verify its bytes/checksum.

Status language:

- **SOURCE CHECKPOINTED** = local Git commit exists and verification passed.
- **DURABLY CHECKPOINTED** = external Library continuation bundle has also been verified.
